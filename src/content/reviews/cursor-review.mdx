## Direct Answer

**Cursor is the leading AI-native code editor: $20/month for the Pro plan, with a free Hobby tier to start.** Its strength is doing agentic, multi-file work inside a familiar VS Code-style IDE with frontier-model access. Its cost model is the caveat — included Agent limits are unpublished, and heavy agent users climb to Pro+ (3x limits) or Ultra (20x limits) or pay usage-based overflow. If your workflow is delegating whole tasks from a terminal, [Claude Code](/guides/how-to-use-claude-code) is the closer fit at the same $20 entry price.

## What Is Cursor?

Cursor (by Anysphere) is a code editor forked from the VS Code lineage and rebuilt around AI: inline edits, a codebase-aware chat, Composer for larger structured changes, and an Agent that plans and executes multi-file modifications. It supports MCP servers, skills, hooks, and cloud agents that run work in the background.

Its competitive set in 2026 is: **Claude Code** (Anthropic's terminal-first coding agent), **OpenAI Codex** (delegated cloud coding agent), and **GitHub Copilot** (autocomplete-plus-chat inside your existing editor). These form factors overlap but reward different working styles — see [Cursor vs Claude Code vs Codex](/comparisons/cursor-vs-claude-code-vs-codex).

## Pricing and the Limits Question

Verified plans ([details](/pricing/cursor)): free Hobby with limited Agent requests; Pro at $20/month with "extended" Agent limits plus usage-based billing beyond them; Pro+ and Ultra at 3x and 20x Pro's included Agent usage; Teams at $40/user/month with SSO and team privacy mode; custom Enterprise with pooled usage.

The honest read: **$20/month covers typical daily use; heavy agentic refactoring does not have a predictable flat price.** Cursor does not publish a fixed request quota, which the community regularly flags. If your work is sustained agent sessions across a large repo, budget for Pro+/Ultra or usage overflow — and compare against Claude plans, whose limits are also usage-shaped but bundle Claude Code with chat.

## Best For / Not Ideal For

**Best for:**

- Developers who spend their day in an editor and want AI edits as reviewable diffs.
- Multi-file refactors and feature work with repo-wide context.
- Teams wanting admin controls, agentic code review, and SSO ($40/user Teams plan).

**Not ideal for:**

- Terminal-and-CI-centric workflows or "run this task and report back" delegation — Claude Code's home ground.
- Developers happy with autocomplete and chat only — Copilot costs less.
- Occasional coders — the free Hobby tier or a chat assistant may be all you need.

## Limitations Worth Knowing

- **Unpublished Agent quotas** make budgeting imprecise; the tier ladder (Pro → Pro+ → Ultra) exists because people hit them.
- **Editor switch required** if you are not on VS Code already (keybindings/extensions mostly carry over from VS Code).
- **Team privacy mode matters:** on individual plans, review the current data-handling settings for your codebase's sensitivity.

## Alternatives

- **Claude Code** — terminal-first agent included in Claude paid plans (from $20/month); our guide: [How to use Claude Code](/guides/how-to-use-claude-code).
- **OpenAI Codex** — delegated cloud coding agent tied to ChatGPT plans; our guide: [How to use Codex](/guides/how-to-use-openai-codex).
- **GitHub Copilot** — cheapest path to AI-assisted coding inside your current editor (not yet profiled by us).

## Final Recommendation

Choose **Cursor Pro ($20/month)** if the IDE is where you live and you want agentic edits with diffs and repo context. Choose **Claude Code** if you delegate whole tasks from a terminal or CI. Running both is common in professional setups — one for interactive editing, one for delegated work.
